# Школково — мониторинг чатов

Расширение помогает кураторам замечать новые вопросы, находить свободные чаты и отслеживать передачу смены. Оно проверяет переписки в отдельной вкладке Школково и показывает уведомления с учётом расписания. Все часы в интерфейсе указаны по Москве.

[Техническое описание](TECHNICAL.md) · [Журнал изменений](CHANGELOG.md)

## Подготовить расписание

Если вы получили настроенную сборку, переходите к установке. Для свежей копии репозитория сделайте копию шаблона и назовите её `schedule-config.json`. Положите файл рядом с `manifest.json` выбранной версии. [Шаблон настройки](schedule-config.example.json)

| Браузер | Куда положить файл |
| --- | --- |
| Chrome | `chrome/schedule-config.json` |
| Firefox | `firefox/extension/schedule-config.json` |
| Safari | `safari/WebExtension/schedule-config.json` |

Заполните `spreadsheetId` идентификатором Google Таблицы из части адреса после `/spreadsheets/d/`. В `entryGid` впишите цифры из `gid` известной вкладки той же таблицы, которая отображается в списке листов. Оба значения укажите в кавычках. Используйте таблицу расписания команды, доступную для чтения без входа в Google. Если у вас уже есть настроенная копия расширения из этого репозитория, перенесите её `schedule-config.json` в новую папку перед обновлением или сборкой.

Собранные пакеты содержат локальный файл настроек расписания. Передавайте настроенную сборку тем, у кого есть доступ к этому расписанию.

## Установить расширение

### Chrome

1. В Chrome 120 или новее откройте `chrome://extensions` и включите **Режим разработчика**.
2. Нажмите **Загрузить распакованное расширение** и выберите папку `chrome`.
3. После изменения файлов нажмите значок перезагрузки на карточке расширения и обновите вкладку Школково. [Загрузка распакованного расширения в Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)

### Firefox

1. В Firefox 140 или новее откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **Загрузить временное дополнение** и выберите `firefox/extension/manifest.json`. В качестве исходника также можно выбрать собранный `.xpi`.
3. После изменения исходников нажмите **Перезагрузить** на карточке дополнения и обновите вкладку Школково. Для обновления файла `.xpi` соберите его заново и загрузите новую копию.

Временная установка действует до перезапуска Firefox. Чтобы собрать пакет, из папки репозитория выполните в PowerShell команду `./firefox/build-xpi.ps1`. Файл появится в `firefox/dist`. Для постоянной установки в обычном Firefox нужен `.xpi` с подписью Mozilla. [Временная установка](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/) · [Подпись дополнений](https://extensionworkshop.com/documentation/publish/signing-and-distribution-overview/)

### Safari

Нужны macOS 14.4, Safari 17.4 или новее и Xcode. Перенесите всю папку `safari` на Mac вместе с локальным `schedule-config.json` внутри `WebExtension`.

1. Откройте `ShkolkovoSafari.xcodeproj` в Xcode. Выберите схему **ShkolkovoSafari** и устройство **My Mac**.
2. В **Signing & Capabilities** проверьте подпись приложения и расширения. Для локальной сборки можно выбрать **Sign to Run Locally**. Нажмите **Run**.
3. Включите «Школково» в **Safari → Настройки → Расширения**. Для локальной сборки без сертификата разработчика Safari может потребовать **Allow Unsigned Extensions** в разделе **Разработка**.
4. Дайте расширению постоянный доступ к `1.shkolkovo.online` и `docs.google.com`.

Для сборки из Терминала выполните две команды из папки `safari`.

```bash
bash ./build-macos.sh
open ./build/Build/Products/Release/ShkolkovoSafari.app
```

Скрипт по умолчанию подписывает приложение для запуска на своём Mac. Для подписи командой Apple выберите её в Xcode или передайте `SHKOLKOVO_TEAM_ID` при запуске скрипта. Для обновления пересоберите проект, запустите новую сборку и перезапустите Safari. [Запуск расширения в Xcode](https://developer.apple.com/documentation/safariservices/running-your-safari-web-extension) · [Права доступа в Safari](https://developer.apple.com/documentation/safariservices/managing-safari-web-extension-permissions)

Если меню открывается пустым, проверьте, что в настройках Safari у расширения указана версия 1.9.2. Для диагностики откройте меню расширения, затем выберите **Разработка → этот Mac → Extension Popup Page** и посмотрите первую ошибку в консоли. Сообщение «Фоновый скрипт Safari не ответил» относится к отдельной консоли **Разработка → Web Extension Background Content**. [Диагностика Safari у Apple](https://developer.apple.com/documentation/safariservices/troubleshooting-your-safari-web-extension)

## Запустить мониторинг

1. Войдите в Школково в том же профиле браузера и откройте страницу чатов.
2. Откройте меню «Школково — свободные чаты». При первом запуске введите имя и фамилию как в расписании и нажмите **Сохранить**. Имя хранится отдельно в каждом профиле браузера.
3. Нажмите **Проверить уведомления**. В Safari разрешите уведомления от приложения «Школково для Safari», когда macOS запросит доступ.
4. В Safari откройте меню с панели инструментов в той вкладке чатов, которую хотите использовать для проверки. Нажмите **Запустить мониторинг**. В Chrome и Firefox кнопка открывает отдельную вкладку проверки.

Оставьте вкладку проверки в фоне и работайте с чатами из другой вкладки. При открытии переписки сайт может отметить её прочитанной.

В Safari обновление страницы чатов продолжает мониторинг в той же вкладке. Если закрыть выбранную вкладку, уйти с неё со страницы чатов или полностью перезапустить Safari, откройте нужную вкладку и снова нажмите **Запустить мониторинг**.

Проверка идёт от начала списка до границы в 45 минут и возвращается наверх для обнаружения новых чатов. Для анализа переписки учитывается активность моложе 20 минут. Если старые закреплённые или непрочитанные строки скрывают свежие группы ниже по списку, меню показывает частичный просмотр.

**Остановить проверку** приостанавливает мониторинг и сохраняет привязки. **Завершить смену и сбросить привязки** останавливает мониторинг и очищает рабочий список чатов и привязок. Имя и настройки режима сохраняются.

## Работать с чатами

### Свободные и закреплённые чаты

- Разверните **Свободные чаты** в меню. Там видны подтверждённые чаты, ожидающие ответа, и чаты, оставшиеся на передачу. Кнопка **×** убирает запись из списка расширения. Следующий вопрос в этой переписке может снова вернуть чат в список.
- Включите **Мгновенные уведомления о закреплённых чатах**, чтобы получать оповещения о новых сообщениях учеников. В обычном режиме переключатель действует на свои и свободные закреплённые чаты. В режиме старшего он учитывает настройку уведомлений конкретного чата.
- При продолжающемся ожидании обычный режим напоминает о подходящих свободных и закреплённых чатах через 5, 7 и 10 минут. Режим старшего напоминает о свободных чатах с 5-й минуты, а о занятых чатах с включёнными уведомлениями с 6-й. Затем напоминания повторяются через 2 минуты, пока переписка остаётся в проверяемом окне и ждёт ответа.
- С `:55` МСК оповещения о передаче смены получают кураторы из расписания на следующий час. Передача касается свежих переписок, которые продолжают ждать ответа после окончания дежурства прежнего куратора.

### Вкладка старшего

Включите **Режим старшего** и нажмите **Открыть вкладку старшего**. Она группирует занятые чаты по кураторам и показывает время последнего сообщения ученика, последнего ответа куратора и длительность ожидания. Нажмите название чата, чтобы открыть переписку. В столбце **Действия** можно выключить уведомления для чата или снять привязку.

Чат с ожиданием больше шести минут остаётся в таблице текущего часа. В `:00` МСК список и счётчики начинают новый календарный час. Напоминания продолжаются и для чатов, скрытых на границе часа, пока сохраняется ожидание, действует привязка и включены уведомления. Чат прошлого часа снова появится у своего куратора после подтверждённого сообщения ученика или куратора в текущем часе.

Если начало ожидания старше 12 часов, расширение ищет следующее сообщение ученика, которое требует ответа и пришло за последние 20 минут. Ожидание считается от этого сообщения. Чаты с подтверждённым последним сообщением ученика старше 12 часов исключаются из базы активных чатов.

В Safari системные уведомления доставляет приложение macOS. Для перехода в конкретную переписку используйте название чата во вкладке старшего.

## Изменить имя куратора

Откройте `curator.json` рядом с `manifest.json`. Заполните `firstName` и `lastName` в кавычках так, как имя записано в расписании. Заполненные поля файла имеют приоритет над именем, сохранённым в меню.

| Браузер | Как применить изменение |
| --- | --- |
| Chrome | Сохраните `chrome/curator.json`. Перезагрузите расширение на `chrome://extensions` и обновите вкладку чатов. |
| Firefox | Сохраните `firefox/extension/curator.json`. Перезагрузите дополнение из исходников через `about:debugging` и обновите вкладку чатов. Для установки из `.xpi` подготовьте новый пакет. |
| Safari | Сохраните `safari/WebExtension/curator.json`. Пересоберите приложение, запустите новую сборку и перезапустите Safari. |

Оставляйте оба поля пустыми при передаче исходников или установочной сборки коллегам, чтобы каждый куратор вводил свои данные в меню.

## Проверить, что мониторинг работает

| Что видно в меню | Что сделать |
| --- | --- |
| **Ожидаю загрузку списка чатов** | Проверьте вход в Школково в этом профиле, доступ расширения к сайту и загрузку вкладки проверки. После обновления расширения обновите вкладку. |
| **Не удалось обновить расписание** | Проверьте наличие `schedule-config.json`, значения `spreadsheetId` и `entryGid`, доступ к таблице и наличие строки на нужный час. Подробность ошибки и следующий повтор отображаются в меню, когда они известны. |
| **Платформа подключается** или **Платформа не в сети** | Проверьте состояние Школково в рабочей вкладке. Оповещение об офлайне возможно после подтверждённого `online` этой страницы и двух секунд непрерывного `offline`. |
| **Не определено** | Указанные чаты требуют повторной проверки. Расширение учитывает активность за последние 20 минут. Сверьте нужный чат в Школково, если его статус важен сейчас. |
| Уведомление не появилось | Нажмите **Проверить уведомления**. Если результата нет, проверьте разрешения системы для браузера или приложения «Школково для Safari» и режим фокусирования. Для закреплённых чатов также проверьте переключатель мгновенных уведомлений. |

В меню **Состав на час** показывает, для какого часа используется расписание. **Таблица прочитана** помогает проверить свежесть данных. На границе смены часы в этом блоке и во вкладке старшего могут различаться. Расписание следующей смены применяется с `:55`, а список старшего обновляет отчётный час в `:00`.
