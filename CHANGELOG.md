# Журнал изменений

## 1.11.7 — 2026-11-28

### Chrome

- Журнал смены связывает проверку чата, решение об уведомлении, ожидание, отмену и ответ Chrome по случайным ссылкам.
- Записываются источник, точность, смещение и UTC-время проверенной метки, а также причина отклонения точной метки и разница с отображаемой минутой.

## 1.11.6 — 2026-11-28

### Chrome

- Метки чатов без пояса разбираются по местному времени браузера. Точные метки `datetime` учитывают указанный пояс. Расписание загружается на московские дату и час.
- Первое уведомление о свободном чате ждёт повторной проверки после нового сообщения ученика. Эпизод отмечается оповещённым после успешной отправки в Chrome.

## 1.11.5 — 2026-11-27

### Chrome

- Журнал проверяет пропущенные часы после подтверждения дежурства или по сохранённой очереди. Это устраняет запросы за 1970 год.
- Восстановление повторно проверяет одноимённые чаты по актуальному списку и ставит оставшуюся уникальную строку в очередь.
- При чтении учитывается точность времени сообщения. Если отметка без секунд пересекает границу окна проверки, журнал записывает `message_time_unconfirmed`.
- Причина ожидания начального просмотра видна в меню до загрузки списка и записывается в журнал смены.

## 1.11.3 — 2026-11-27

### Chrome

- Старые строки задают границу поиска только после проверки пропущенных позиций. Недоступный участок получает код `row_range_unavailable`.
- Начальный просмотр трактует отметку без секунд как интервал всей минуты. Одноимённые чаты без собственного ID учитываются как неоднозначные позиции.
- Для сохранённых пропусков с позициями из 1.11.1 заново проверяются соседние строки в исходном временном окне.
- Занятая вкладка приостанавливает всю очередь до завершения текущего чтения. `schedule_failed` содержит код причины сбоя загрузки расписания.

## 1.11.2 — 2026-11-27

### Chrome

- При перестановке строк обход сохраняет найденные чаты и повторно проверяет участок перед продвижением отметки.
- Для восстановления пропущенных позиций используются соседние строки начального обхода. Счётчик просмотра учитывает уникальные чаты.
- Поиск учитывает всю минуту для строк без секунд. Журнал отдельно отмечает остановку по временной границе кодом `row_time_boundary`.

## 1.11.1 — 2026-11-27

### Chrome

- Пропущенные позиции начального обзора сохраняются в очереди и обрабатываются пакетами по восемь. Перезагрузка вкладки сохраняет очередь и текущий пакет.
- Обычный обход продвигает отметку просмотра только после непрерывного прохода.
- Журнал записывает коды отказов чтения, включая ошибки проверки полученной истории.
- Журнал распределяет события по подтверждённым часам смены после задержки расписания и учитывает время перенесённых событий в заголовке.
- Сбой сохранения при ручном запуске закрывает созданную этой попыткой вкладку.

## 1.11.0 — 2026-11-27

### Chrome

- Начальный обход отправляет распознанные чаты в очередь по мере просмотра. Меню показывает число пропусков, а их обработка продолжается отдельно.
- Планировщик освобождает задачи при откате. Уведомления об офлайне ждут повторного подтверждения, если состояние подключения временно неизвестно.
- Для недоступной вкладки проверки добавлена диагностика и кнопка возврата к чатам.
- Расписание учитывает часы с нулём дежурных и пересматривает привязки при изменении состава внутри часа. Старые записи без подтверждённого сообщения ученика очищаются по активности.
- Журнал перепроверяет пропущенные часы после сна и использует сопоставление имён с учётом отчества. При резервной выгрузке файл сохраняется с расширением `.log`, а меню показывает фактическое имя.
- Сбой показа уведомления о новой версии оставляет его в очереди на повтор.

## 1.10.4 — 2026-11-27

### Chrome

- Добавлена проверка версии в ветке `chrome` на GitHub. При выпуске более новой версии меню предлагает скачать архив, а Chrome показывает уведомление.

## 1.10.3 — 2026-11-27

### Chrome

- Мониторинг восстанавливает фоновую вкладку после её закрытия и продолжает работу с сохранённой очередью.
- При блокировке вкладки очередь ждёт одной общей попытки. Меню и журнал показывают причину ожидания.
- При запуске расширение один раз просматривает начало отсортированного списка за 45 минут и ставит эти чаты в очередь. После этого обрабатывает новые и непрочитанные чаты и изменения в чатах с привязкой.

## 1.10.2 — 2026-11-26

### Chrome

- Меню показывает полный интервал текущего состава по Москве и местное время этого интервала при разнице часовых поясов.
- Для запроса таблицы, интервала в меню и записи о расписании в журнале используется общий расчёт московских даты и часа.

## 1.10.1 — 2026-11-26

### Chrome

- Добавлен журнал сеанса мониторинга с автоматической выгрузкой после окончания смены по расписанию или ручного завершения.
- Добавлен выбор папки расширения для файлов журнала и резервное сохранение в папку загрузок Chrome.

## 1.10.0 — 2026-11-26

- Chrome, Firefox и Safari автоматически определяют часовой пояс устройства. Меню, вкладка старшего и уведомления показывают местные дату, время и смещение UTC.
- Основной состав загружается на фактические дату и час в Москве. Данные следующего часа загружаются отдельно для передачи чатов с `:55` МСК.

## 1.9.2 — 2026-11-26

- Safari привязывает мониторинг к открытой пользователем вкладке чатов при нажатии **Запустить мониторинг**. После закрытия вкладки, ухода со страницы чатов или перезапуска Safari проверку нужно запустить вручную.

## 1.9.1 — 2026-11-25

- Вкладка старшего показывает чаты текущего часа при ожидании больше шести минут. В `:00` список обновляется по календарному часу, а напоминания продолжают работать по настройкам чата.
- Если начало ожидания старше 12 часов, расширение проверяет следующие сообщения ученика и берёт первый вопрос, пришедший за последние 20 минут. Чат с подтверждённым последним сообщением ученика старше 12 часов исключается из базы активных чатов.

## 1.9.0 — 2026-11-25

- Уведомление `offline` отправляется после двух секунд непрерывного офлайна. После загрузки страницы сначала требуется подтвердить `online`.
- Автоматическая прокрутка списка ограничена 45 минутами от текущего времени. После прохода расширение возвращается к началу списка и проверяет новые строки.
- Вкладка старшего скрывает чаты с ожиданием больше шести минут и исключает их из счётчика. Для скрытых чатов продолжают действовать индивидуальные настройки уведомлений.
- В таблице старшего указывается время последнего сообщения ученика. Время последнего ответа куратора показано отдельно.

## 1.8.1 — 2026-11-25

### Safari

- Меню получает фиксированную ширину для расчёта размера всплывающего окна Safari.
- Запросы статуса выполняются последовательно. Если фоновый скрипт задерживает ответ, меню показывает ошибку и повторяет проверку.
- Чтение локального имени куратора ограничено по времени, чтобы при задержке загрузки файла меню оставалось доступным.

## 1.8.0 — 2026-11-24

### Добавлено

- Chrome, Firefox и Safari собраны в одном репозитории. У Firefox есть скрипт сборки XPI, у Safari — проект Xcode и скрипт сборки приложения для macOS.
- При первом запуске куратор вводит имя и фамилию из расписания. После сохранения форма скрывается. Для ручной смены имени предусмотрен `curator.json`.
- Вкладка старшего показывает количество чатов с сообщениями в текущем московском часе. В `:00` чаты предыдущего часа скрываются, а после нового сообщения ученика или куратора чат возвращается в список своего куратора.
- В репозитории есть руководство по установке и работе, техническое описание и пример локальных настроек Google Таблицы.

### Исправлено

- Мгновенные уведомления о новых сообщениях ученика работают в закреплённых чатах, привязанных к самому куратору. В режиме старшего мгновенные уведомления учитывают выключение уведомлений для конкретного чата.
- Новые сообщения в пределах одной минуты различаются по идентификаторам в истории, когда площадка их предоставляет.
- С `:55` уведомления о передаче своих и чужих чатов получают только кураторы, чьё дежурство на следующий час подтверждено расписанием.
