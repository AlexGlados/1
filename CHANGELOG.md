# Журнал изменений

## 1.8.0 — 2026-11-24

### Добавлено

- Chrome, Firefox и Safari собраны в одном репозитории. У Firefox есть скрипт сборки XPI, у Safari — проект Xcode и скрипт сборки приложения для macOS.
- При первом запуске куратор вводит имя и фамилию из расписания. После сохранения форма скрывается. Для ручной смены имени предусмотрен `curator.json`.
- Вкладка старшего показывает количество чатов с сообщениями в текущем московском часе. В `:00` чаты предыдущего часа скрываются, а после нового сообщения ученика или куратора чат возвращается в список своего куратора.
- В репозитории есть руководство по установке и работе, техническое описание и пример локальных настроек Google Таблицы.

### Исправлено

- Мгновенные уведомления о новых сообщениях ученика работают в закреплённых чатах, привязанных к самому куратору. В режиме старшего мгновенные уведомления учитывают выключение уведомлений для конкретного чата.
- Новые сообщения в пределах одной минуты различаются по идентификаторам в истории, когда площадка их предоставляет.
- С `:55` уведомления о передаче своих и чужих чатов получают только кураторы, чьё дежурство на следующий час подтверждено расписанием.
